# FPV War

## Запуск
1. Установи Node.js (версия 14 или новее): https://nodejs.org
2. В папке проекта выполни:
   ```
   npm start
   ```
   (или `node server.js`)
3. Открой в браузере http://localhost:3000

Другой порт: `PORT=8080 node server.js` (в Windows: `set PORT=8080 && node server.js`).

## Структура
- `server.js` — веб-сервер (без зависимостей), раздаёт папку `public`
- `public/index.html` — сама игра
- `package.json` — описание проекта

## Игра по сети
Серверы в игре работают через PeerJS (скрипт и сигнальный сервер берутся из интернета),
поэтому для онлайна нужен интернет. Чтобы играть с телефона, открой на нём адрес
компьютера в локальной сети, например http://192.168.1.10:3000
(для онлайн-режима лучше выложить игру на любой хостинг с Node.js).
